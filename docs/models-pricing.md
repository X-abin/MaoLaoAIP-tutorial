# 模型与价格

这一页的数据来自 MaoLao API 的公开价格接口，构建文档时会自动同步为本地快照。

::: tip
模型、分组和倍率变化比较频繁。正式使用前，建议重新运行 `pnpm data:sync` 或查看 MaoLao API 控制台里的实时价格。
:::

## 怎样读这张表

- **模型**：调用时填写的 `model` 名称，必须精确匹配。
- **供应商**：模型所属来源，例如 OpenAI、Anthropic、DeepSeek、Google、xAI 等。
- **计费**：文本模型通常显示输入倍率和输出倍率；图片、视频等模型可能显示固定价格。
- **可用分组**：只有 Key 所在分组支持该模型时，调用才会成功。
- **端点**：表示模型支持的接口格式，例如 OpenAI Chat、OpenAI Responses、Anthropic Messages 或图片接口。

## 选择模型的实用建议

新手不要一开始追求最贵或最新模型。先用低成本模型验证流程，确认 API Key、Base URL、模型名和客户端配置都正确，再切换到更强模型。

对稳定工作流，建议固定一套组合：

| 用途 | 选择重点 |
| --- | --- |
| 日常问答 | 低倍率、响应快、支持 OpenAI 端点 |
| 编程协作 | 代码能力、上下文长度、客户端兼容性 |
| 长文本 | 上下文、缓存命中、输出价格 |
| 图片生成 | 固定价格、分辨率、异步任务支持 |
| 批量任务 | 低倍率、稳定分组、额度上限 |
