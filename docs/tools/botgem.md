# BotGem

BotGem 是聊天客户端类工具。接入 MaoLao API 时，重点看它是否支持 OpenAI Compatible 或自定义 API 地址。

## 下载地址

- 官方网站：[https://botgem.com](https://botgem.com)
- 新手建议：如果官网提供桌面版，优先下载桌面版；网页版或移动端是否支持自定义 API，要以当前版本为准。

## 配置步骤

1. 打开 BotGem 设置。
2. 找到模型服务、Provider 或 API 设置。
3. 选择 OpenAI Compatible 或 Custom OpenAI。
4. Base URL 填 `https://api.maolaoapi.cc/v1`。
5. API Key 填 MaoLao API Key。
6. 模型名填完整模型名。
7. 保存后发送“请回复 ok”测试。

## 常见问题

- 没有 Base URL 输入框：当前版本可能不能接入 MaoLao API。
- 模型列表为空：尝试手动添加模型名。
- 消耗偏高：检查是否开启长历史上下文。
