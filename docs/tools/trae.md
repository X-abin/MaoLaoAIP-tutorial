# Trae

Trae 接入时重点看它是否支持自定义 OpenAI Compatible Provider。

## 配置步骤

1. 打开 Trae 设置。
2. 找到 AI Provider 或 Model Provider。
3. 新增自定义 OpenAI 兼容服务。
4. 填入 Base URL：`https://api.maolaoapi.cc/v1`。
5. 填入 MaoLao API Key。
6. 填入模型名并保存。

## 使用建议

- 代码类任务优先选择代码能力强的模型。
- 长项目分析前先关闭不必要上下文。
- 如果频繁重试，检查账户日志，避免后台重试造成额度消耗。
