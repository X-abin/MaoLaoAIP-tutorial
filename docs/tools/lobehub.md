# LobeHub / LobeChat

LobeHub 常见产品是 LobeChat。它可以通过 OpenAI 兼容方式接入第三方模型服务，适合搭建自己的网页聊天工具。

## 下载地址

- 官方网站：[https://lobehub.com](https://lobehub.com)
- LobeChat GitHub：[https://github.com/lobehub/lobe-chat](https://github.com/lobehub/lobe-chat)
- 新手建议：如果你只是个人使用，可以先看在线版或一键部署方式；服务器部署再考虑环境变量。

## 配置步骤

1. 打开 LobeChat 设置或部署配置。
2. 找到 OpenAI Provider。
3. Base URL 填 `https://api.maolaoapi.cc/v1`。
4. API Key 填 MaoLao API Key。
5. 模型名填完整名称。
6. 保存后发送一句短消息测试。

## 部署提醒

如果你是自己部署 LobeChat，Key 可能要写在环境变量中。不要把真实 Key 写进公开仓库。
